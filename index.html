Integration Guide

API usage examples for text and image models.

1. Text Generation (JavaScript)

fetch("https://crystal-api.baddampujithareddy19.workers.dev/", { method: "POST", headers: { "X-Crystal-Key": "YOUR_CRYSTAL_KEY", "Content-Type": "application/json" }, body: JSON.stringify({ model: "@cf/meta/llama-3.1-8b-instruct-fp8-fast", prompt: "Write a sorting algorithm in JavaScript" }) }) .then(res => res.json()) .then(data => console.log(data.result));

2. Image Generation (Returns Base64 Data URL)

fetch("https://crystal-api.baddampujithareddy19.workers.dev/", { method: "POST", headers: { "X-Crystal-Key": "YOUR_CRYSTAL_KEY", "Content-Type": "application/json" }, body: JSON.stringify({ model: "@cf/black-forest-labs/flux-1-schnell", prompt: "A beautiful dragon flying over snow mountains" }) }) .then(res => res.json()) .then(data => { // data.result is "data:image/png;base64,..." document.getElementById("myImage").src = data.result; });
