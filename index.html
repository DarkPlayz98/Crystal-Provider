Live tester

Runs a single inference call through the worker with the key and params below.

Generate key

Creates a new cry_live_ key via the worker's admin route. Requires the admin secret — this is a destructive-adjacent action, treat the secret like a password, not a query param.

Revoke key

Deactivates a key immediately. This does not delete the log history tied to it.

Allowed models

Pulled from the worker's ALLOWED_MODELS set. Any other model string sent in a request falls back to the default silently — this list is the ground truth, not a wishlist.

To add a model here, add it to ALLOWED_MODELS in worker.js and redeploy. This page reads from that same list — nothing shown here is decorative.

Integration

Chat endpoint. Auth via header, not query string.

POST /
Headers:
  X-Crystal-Key: cry_live_…
  Content-Type: application/json

Body:
{
  "model": "@cf/meta/llama-3.1-8b-instruct-fp8-fast",
  "prompt": "Hello world",
  "max_tokens": 2048,
  "temperature": 0.7
}

Response shape on success:

{
  "status": "success",
  "model_used": "…",
  "request_id": "…",
  "rate_limit_remaining": 19,
  "verification": {
    "authentic_cf_ray": "…",
    "datacenter_colo": "…",
    "client_country": "…",
    "gpu_execution_latency_ms": 412
  },
  "result": "…"
}

Rate limit: 20 requests / 60s per key. A 429 includes a Retry-After header.

Admin routes (/v1/create-key, /v1/revoke-key, /v1/requests) require X-Admin-Secret and are not callable from a browser unless ADMIN_ALLOWED_ORIGIN is set to this page's origin on the worker.
