How to Use Crystal Provider

Integrate your generated keys into any web browser, Discord bot, or mobile app.

⚡ Each key gets 20,000,000 Tokens

1. Authentication

Pass your API key in the X-Crystal-Key header of your POST requests.

2. API Endpoint

POST https://crystal-api.baddampujithareddy19.workers.dev/

3. Code Examples

fetch("https://crystal-api.baddampujithareddy19.workers.dev/", { method: "POST", headers: { "X-Crystal-Key": "YOUR_CRYSTAL_KEY", "Content-Type": "application/json" }, body: JSON.stringify({ prompt: "Write a quick sorting algorithm in JS", model: "@cf/meta/llama-3.1-8b-instruct-fp8-fast", max_tokens: 2048, temperature: 0.7 }) }) .then(res => res.json()) .then(data => console.log(data.result));
import requests url = "https://crystal-api.baddampujithareddy19.workers.dev/" headers = { "X-Crystal-Key": "YOUR_CRYSTAL_KEY", "Content-Type": "application/json" } payload = { "prompt": "Hello world!", "max_tokens": 2048 } response = requests.post(url, headers=headers, json=payload) print(response.json()["result"])
